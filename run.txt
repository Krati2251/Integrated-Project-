MANUAL DOCKER STARTUP (For Presentation):
═══════════════════════════════════════════════════════════════════

OPTION 1: Using docker-compose (Easiest):
Set-Location "D:\Triage Agent Final\finance-support-triage-agent-final-streamlit-1"
docker-compose up -d

Then open: http://127.0.0.1:8501


OPTION 2: Manual Docker Commands (Step-by-step):

# Step 1: Create network
docker network create finance-net

# Step 2: Stop old containers if running
docker rm -f finance-backend finance-frontend finance-quiz 2>$null

# Step 3: Start Backend (API)
docker run -d --name finance-backend --network finance-net --env-file ".env" -p 8000:8000 finance-backend:latest

# Step 4: Start Frontend (Dashboard) - Wait 10 seconds for backend
Start-Sleep -Seconds 10
docker run -d --name finance-frontend --network finance-net --env-file ".env" -e API_BASE_URL=http://finance-backend:8000 -p 8501:8501 finance-frontend:latest

# Step 5: Start Quiz Service
docker run -d --name finance-quiz --network finance-net --env-file ".env" -e BACKEND_API_URL=http://finance-backend:8000 -p 8502:8501 finance-quiz:latest

Then open: http://127.0.0.1:8501


OPTION 3: Check if containers are running:
docker ps

OPTION 4: Stop all containers:
docker-compose down
OR
docker rm -f finance-backend finance-frontend finance-quiz
